- Scope = text novels only.
- Do not treat ENGINE PASS as SEARCH PASS.
- Do not use generic `tiên` probes as proof; identity gate uses a title discovered from the same source.
- First search call page token must be empty.
- NFC/NFD are hard requirements for maintained text sources; accentless is capability/WARN unless explicitly implemented.
- Do not promote candidate packages based on Node/local parsing alone.
- Candidate physical gate must isolate candidate registry and force reinstall exact extension version.
- iOS PASS requires iOS user/runtime confirmation; Android PASS is not iOS PASS.
